Vis-Sam-3D Suite Setup Guide

Interactive object segmentation & dual-stage 3D reconstruction pipeline connected to free Kaggle Dual-GPU acceleration.

Workflow Pipeline Architecture

1

Upload Image

Drop in any object photograph, webcam capture, or choose from the 16 pre-reconstructed daily objects library.

2

Segment / Masking

Interactive Canvas with green (+ Point), red (- Point), Box bounds, precision brush, or 1-click AI Auto-Segmentation.

3

3D Studio & Export

Dual-stage diffusion, watertight marching cubes, and 3D Gaussian Splats rendered interactively in Three.js with GLB download.

Quick Start in 3 Easy Steps

1

Start the Kaggle Free Dual-GPU Notebook

Open Kaggle.com, create a notebook, select GPU T4 x 2 in the accelerator settings, upload kaggle_notebook/SAM_3D_Suite_Kaggle_GPU.ipynb and click Run All.

Copy the public Cloudflare Tunnel URL printed at Cell 5 (https://...trycloudflare.com).

2

Launch Local Web Studio

Double-click start.bat (Windows) or execute ./start.sh (macOS/Linux) in the project folder.

cd frontend
npm install
npm run dev

Opens automatically at http://localhost:3000.

3

Connect & Reconstruct

In the top right header, click Connect Kaggle GPU and paste your Cloudflare Tunnel URL. Upload your photo, click ✨ Auto-Segment, and hit 🚀 Generate 3D Model!
